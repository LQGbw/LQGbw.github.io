## 这个网页做什么

这里是一个个人数字名片，也是一个持续更新的 AI 成长档案，分成三个模块：

- **学习**：基础知识、AI 工具探索、知识问答工作流
- **实验**：可用工具、完整产品、Agent 与多 Agent 的逐步尝试
- **个人介绍**：我在学习什么、如何记录，以及在哪里持续更新

主页会随着实践持续更新，目标是把“学到的东西”整理成别人可以理解、复看和复用的内容。

## 七阶段学习路径

1. **基础知识**：学习 AI 基本概念、模型、提示词和常见方法。
2. **AI 工具探索**：尝试现有 AI 工具，记录真实体验和不成熟的前端实验。
3. **知识问答工作流**：使用 Coze、Dify 等平台搭建知识库、问答和自动化流程。
4. **可用工具开发**：从 Skill、插件和小工具开始，封装真正可用的能力。
5. **完整产品开发**：围绕场景、用户反馈和数据指标，开发更完整的产品。
6. **Agent 开发**：探索模块化 Agent，以及能力组件的自由组合与插拔。
7. **多 Agent 开发**：研究角色分工、协作、调度和可观测性。
