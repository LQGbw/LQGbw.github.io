## 这个网页做什么

这里是一个个人数字名片，也是一个持续更新的 AI 成长档案，分成三个模块：

- **学习**：基础知识、AI 工具探索、行业认知
- **实验**：有实际用途的小型工具、完整产品、Agent / Harness、多 Agent
- **个人介绍**：我学过什么、有什么经历，以及未来的规划想法

主页会随着实践持续更新，目标是把学习、项目经历和未来方向放在同一条成长线上。

## 七阶段成长路径

1. **基础知识**：学习 AI 基本概念、模型、提示词和常见方法。
2. **AI 工具探索**：尝试现有 AI 工具，记录真实体验和不成熟的前端交互实验。
3. **行业认知**：关注 AI 工具、应用场景、产品形态和行业变化，形成自己的判断。
4. **小型实用工具**：从 Skill、插件和小工具开始，解决具体问题，做简单但真正能用的东西。
5. **完整产品**：围绕场景、用户反馈和数据指标，开发更完整、更稳定的产品。
6. **Agent / Harness**：探索 Agent 的开发与编排，让能力可以模块化组合、自由插拔。
7. **多 Agent 开发**：研究角色分工、协作、调度和可观测性。
