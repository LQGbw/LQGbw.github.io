## 这个网页做什么

这里是一个个人数字名片，也是一个持续更新的 AI 学习档案，主要记录：

- AI 学习路线与课程笔记
- AI 工具体验和使用方法
- Skill、Prompt 与自动化资源
- 正在实践的小项目
- 学习过程中的思考与成长记录

主页会随着实践持续更新，目标是把“学到的东西”整理成别人可以理解、使用和复用的内容。

## 页面结构

- **学习路线**：从 AI 工具入门，到 Prompt、工作流和 Skill / 自动化
- **资源库**：整理可复用的 Skill、Prompt、工具清单和学习资料
- **项目展示**：记录正在做的 AI 工具和工作流实验
- **成长记录**：发布阶段性的学习笔记和实践复盘
